# Contributing to Wild West Saloon

Thank you for your interest in contributing to Wild West Saloon!

## How to Contribute

To contribute to this project, please **open a new issue** on the repository:

1. Go to [Issues](https://github.com/marechalg/blackjack/issues)
2. Click **New Issue**
3. Select the appropriate issue template:
   - **Bug Report** - for reporting bugs or issues
   - **Feature Request** - for suggesting new features
4. Fill in the template with as much detail as possible
5. Submit the issue

Our team will review your issue and get back to you!

**Happy contributing! 🤠**
