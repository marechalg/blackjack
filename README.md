# 🃏 Wild West Saloon

**Wild West Saloon** is a modern web Blackjack game—a fun, fast-paced experience set in the dusty, adventurous world of the Old West! Try your luck against the dealer, enjoy a sleek UI, and stake your claim at the saloon tables.

## 🚀 Features

- Classic 21 Blackjack gameplay
- Responsive, modern user interface (mobile & desktop)
- Old West saloon theme: stylish cards, custom background, sound effects
- Intuitive betting system (chips, balance, win/lose tracking)
- Fair dealer AI and clear player/dealer stats
- Session persistence (local storage or account-based, optional)
- Smooth game animations & user feedback
- Customizable settings (sound, color themes, etc.)
- Multiplayer and leaderboard integration

## 💡 Game Rules

- Try to beat the dealer by getting a hand closer to 21 without going over
- Face cards are worth 10; Aces are 1 or 11; numbered cards are face value
- Player and dealer both start with 2 cards. Player can hit (draw) or stand.
- Dealer hits until reaching 17 or more
